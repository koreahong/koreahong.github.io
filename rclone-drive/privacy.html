개인정보처리방침

  • rclone-drive 는 소유자 본인의 Google Drive 를 rclone(오픈소스 명령줄 도구)으로 동기화하는 용도로만 씁니다.
  • Google 사용자 데이터는 사용자 기기의 rclone 이 Google Drive API 와 직접 주고받으며, 별도 서버로 전송 · 저장 · 공유하지 않습니다.
  • 인증 토큰은 사용자 기기의 rclone 설정 파일에만 저장됩니다.
  • 접근 권한은 언제든 Google 계정 권한 페이지에서 해제할 수 있습니다.
  • Google API 서비스에서 받은 정보의 사용은 Limited Use 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.
